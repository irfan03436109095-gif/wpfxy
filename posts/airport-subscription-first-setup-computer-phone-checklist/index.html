一份机场套餐怎么在电脑和手机用？从首台导入到多端验收

星航2026-11-08— 次阅读
客户端教程

你想在电脑浏览资料，出门后又想在手机继续用，一份机场套餐能否做到，要看服务商的设备、同时在线和网络接入规则。先在主力设备上完成一个真实任务，再加第二台。 这样出错时能分清是单台设置有问题，还是两台同时连接触发了限制。

一、付款前写下这两台设备

先决定哪台最常用、两台是否要同时连接，以及手机是否会从家里 Wi-Fi 换到蜂窝网络。再对着套餐面板核对设备数、同时在线、并发或来源 IP 的统计对象。数字看起来相近的套餐，也可能按不同对象计数。家庭共用和路由器的规则另外确认。若其中一台是单位管理的电脑，先按组织流程确认能否安装客户端和调整代理。

想做的事 在套餐面板核对什么
电脑和手机轮流用 设备是否要绑定，换机如何解除旧设备
两台同时访问 同时在线是否允许，设备数、连接数或来源 IP 怎样统计
手机从 Wi-Fi 切到蜂窝 地区和网络限制，切换后是否需要重连
两台共享一份用量 账户总额度、倍率、有效期和重置日
先体验再付款 试用可用格式、到账、期限、套餐总价及售后条件

下单前写一行自己的需求，例如“工作电脑与个人手机都要用，平常轮流，周末有时同时连接”。带着这句话核对说明，比只问“能用几台”更容易得到准确答案。查看多端选购时的核对清单

可从 FlyBit 邀请入口 或 99吧邀请入口 查看当前条件。通过邀请注册或购买，本站可能获得佣金。价格和支持范围按当前套餐面板确认。

二、给每台设备拿对地址

注册后登录面板，先确认试用或套餐状态已生效、流量还有余额。账号和密码用于管理订单与权益。私人订阅地址用于让客户端读取配置，从“我的订阅”或“复制订阅”中取得。请按设备和客户端分别选格式，已有一台成功时，也要确认第二台能用同一地址及协议。

设备 客户端示例 导入前核对
Windows 或 macOS Clash Verge Rev 服务商标注兼容的 Clash/Mihomo 配置，电脑安装包架构正确
Android FlClash 面板确认适配 FlClash 的配置，APK 与本机架构匹配
iPhone Shadowrocket 面板指定的订阅格式，或指向该客户端的一键导入

可以给配置起名“我的电脑”和“我的手机”，方便看当前选中哪一份。名称只是本机备注。私人 URL 和二维码都要按凭据保管，换机时从面板在新设备上重新复制。查看订阅地址与二维码的保管办法

三、先配置电脑

  1. 安装 Clash Verge Rev。Windows 从“设置 → 系统 → 关于”确认 x64 或 ARM64。Mac 从“关于本机”确认 Apple 芯片或 Intel。再按官方说明选择适配的版本。下载安装说明
  2. 打开订阅页，粘贴适配地址并导入。更新完成后确认配置下已有节点，再点选这份配置。已有旧配置时，先记下旧名，便于回退。
  3. 到代理页选策略组里的可用节点，用规则模式开始。开启系统代理，重新打开浏览器页面。系统代理负责让遵循系统设置的软件接入，规则负责决定接入后的分流。
  4. 确认一项任务完成，再试另一个程序。如果浏览器成功而该程序失败，先核对应用代理设置与客户端连接记录。有必要时按官方文档了解 TUN 的虚拟网卡接管方式，记录原设置，方便恢复。官方快速入门

四、分别配置安卓和 iPhone

安卓 FlClash。 从项目发布页选匹配架构的 APK。打开配置页，新增 URL 配置，粘贴面板选出的适配订阅。下载完成后点选配置，模式先选规则，在代理页确认节点后点击启动。系统请求 VPN 权限时，核对应用名称并允许。用浏览器完成一个和电脑相同的小任务，记录是 Wi-Fi 还是蜂窝网络。FlClash 官方项目

iPhone 以 Shadowrocket（小火箭）为例。 从 App Store 查看开发者 Shadow Launch Technology Limited，并确认本地区商店的购买与系统要求。客户端费用与机场套餐分别核算。在新增页选择 Subscribe 或“订阅”，粘贴面板给该客户端的地址，保存并更新。选中可用节点，按面板的基础配置路由，打开连接开关。核对系统提示并允许添加 VPN 配置，然后用 Safari 验收。Shadowrocket App Store

五、先分开验收，再同时连接

选择两台设备都能执行的普通任务，例如打开同一篇资料并加载正文。固定目标，分别记录网络、配置名、节点、任务完成状态。每一轮只增加一个条件，以下记录不需要填写任何私人地址。

轮次 怎样做 如何理解结果
电脑单独 手机断开，电脑刷新同一网页 先确认电脑配置和系统代理跑通
手机单独 电脑断开，手机在相同 Wi-Fi 下重做 定位手机配置或 VPN 授权
两台同时 确认规则允许，再让两台各完成一次任务 若单独可用而同时失败，查在线和并发规则
手机切网 保持其他条件，切到蜂窝并再次发起任务 查看重连结果与来源 IP、网络限制

首次双端验收尽量在同一时段完成。手机的 Wi-Fi 和蜂窝会走不同的接入网络，电脑系统代理与手机 VPN 也可能让同一应用命中不同策略。手机切网后失败时，先等基础网络恢复，再手动重连一次。切网、换节点和改订阅分三轮做，结果才容易解释。

给自己留一份最短记录，分别勾选电脑单独可用、手机单独可用、两台同时可用、手机切网后可恢复。任一项未通过就写下当时的条件，再决定是继续排查还是请客服核对套餐限制。

如果两台都能打开网页，却只有某个应用失败，查看它的请求有没有进入客户端、是否命中预期策略。出现证书错误时暂停访问，核对设备时间、目标域名及证书提示，保留证书验证。若订阅更新失败或单台异常，可先用订阅错误分层表和手机电脑四格对照找卡点。给客服时带上设备型号、客户端、时间与报错，遮住 URL 和二维码。

六、退出与下次连接

电脑关闭本次打开的系统代理和 TUN，再正常退出。手机用应用内开关断开。退出后打开一个普通网页验证基础网络，确认没有意外切换系统代理或自动重连。电脑暂时无法恢复时，按关闭代理后的网络恢复步骤核对原有设置。若不再续费，另到订单页处理扣费安排。下次先核对套餐余额和有效期，再更新现有配置。同一台已验收的设备可以直接复用。
