下载页提供多个文件时，按自己的操作系统、处理器架构和发行说明选择。Windows 的 x64 与 ARM64、Mac 的 Apple 芯片与 Intel 芯片不能仅按文件大小判断。优先阅读正式版的说明；Stash 的购买方式、商店可用地区与费用以其官方页面为准。

安装前看这四项

  1. 从上表的开发者项目或官网进入，核对项目名称和维护者。
  2. 阅读系统要求，选对架构和文件类型。GitHub 中的 Source code 是源码，通常不是可直接安装的软件。
  3. 查看发布说明中的校验信息和安装要求。遇到签名、证书或来源提示时先核实文件，不照搬关闭安全保护的做法。
  4. 向服务商确认所选客户端的订阅格式与支持范围。能下载客户端，不代表每种套餐都兼容。

已有工具，下一步做什么

  • 第一次使用：注册、配置与试用流程。
  • Windows：v2rayN 入门或Clash Verge Rev 教程。
  • Android：v2rayNG 入门。
  • 找不到对应步骤：使用教程总览。
