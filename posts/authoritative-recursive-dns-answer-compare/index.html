权威 DNS 和本地查询结果不同？按记录、缓存与时间做对照

域名记录改过后，服务商说“权威 DNS 已更新”，自己电脑却仍看到旧地址。Microsoft 文档把 DNS 查询分为客户端、递归解析器和权威服务器等环节；递归服务器可缓存记录。Cloudflare 的 TTL 文档也提醒，本地缓存可能使实际体验晚于权威记录变化。判断前先确认比较的是同一个域名、同一种记录类型。

三处结果按时间记下来

  1. 从域名注册或 DNS 管理方确认当前权威 NS 名称。不要把任意公共解析器当作权威服务器。
  2. 在 Windows 上用 nslookup -type=A example.com 权威NS名称 查询权威答案，再对照常用解析器的 nslookup -type=A example.com 解析器地址。若关注 IPv6，两次都改为 AAAA；示例域名需换成实际目标。
  3. 记录查询时间、服务器、返回值和 TTL。若使用 CDN、地理调度或不同区域解析，地址差异不一定代表过期，还需确认服务方配置方式。

示意图：对照同一记录类型的权威答案、递归缓存与本机结果。

从差异走到访问验收

权威已变、递归仍旧时，先按 TTL 与缓存窗口继续观察；权威仍旧，则回头查管理面板和实际生效的 NS。两处相同时，再用真实网页或客户端任务判断故障是否还存在。DNS 对照只说明解析链上的一环，不证明机场线路快慢，也不建议为“立刻变新”盲目清空所有设备设置。
