IP 查询怎样使用


    

  • 点击“查询我的 IP”，查看这次请求实际使用的公网出口；切换网络或代理后，可以再次查询进行比较。
    • 

  • 输入一个公网 IPv4 或 IPv6 地址，可查询该地址的数据库资料。这里不查询域名，也不显示局域网设备地址。
    • 

  • 国家、地区、城市和 ASN 来自第三方数据库，只能作为线索，不能定位个人住址，也不能单凭这些资料判断是否使用了 VPN。
    • 

  • 代理分流、IPv4 / IPv6 和访问目标不同，可能产生不同出口；一次查询不等于设备所有流量都走同一条路径。
    • 



Ping 结果怎样理解


浏览器 HTTP 测试


从你当前浏览器顺序发出五次小请求，可随时取消；结果展示响应次数、HTTP 状态及可读响应的最短、平均、最长耗时。这种测试不能发送系统 ICMP 报文。


测试包含可能发生的 DNS 查询、连接建立、TLS 和服务端处理，不是纯网络往返时间，也不是下载测速。首轮与后续轮次可能不同，应固定设备、网络和目标再比较。


自定义目标仅支持 HTTPS，并需要允许浏览器跨域读取。超时、浏览器跨域限制和网络异常都可能导致测试失败，因此不能仅凭本页失败判定目标离线。收到 HTTP 403、404 或 500 说明有服务器返回状态，不应当作 ICMP 丢包。


远程 ICMP 测试


由 Globalping 在所选地区的一台远程探针向目标发送五个 ICMP 包，展示实际收到的包数、丢包率和往返时间，以及探针所在城市和网络。它反映远程探针到目标的路径，不代表当前电脑、手机或代理出口的延迟。


可输入公网 IP 或域名，不要输入网址路径、账户、密钥或机密主机名。目标和测量结果属于公开数据。点击“停止等待”只停止当前浏览器的请求和轮询，已经派发的远程测量仍可能完成。


数据来源与隐私


仅在你点击查询或开始测试后，浏览器才向对应服务发送请求；该服务可以看到请求的公网出口 IP。结果显示在当前页面，本站工具不会将查询的 IP 或自定义目标写入浏览器存储，也不会主动将它们发送到站点统计。


    

  • IP 与归属地由 FreeIPAPI 提供；查询当前 IP 时，服务不可用可降级至 ipify，降级结果不含归属地。第三方服务的日志和数据处理见 FreeIPAPI 隐私说明。
    • 

  • HTTP 测试提供本站小资源、Cloudflare 和 ipify 目标，也可输入自己要检查的公开 HTTPS 地址。
    • 

  • 远程 ICMP 测试由 Globalping 提供，每次仅使用一台探针；匿名访问有免费额度限制。结果公开规则见 Globalping 条款。
    • 

  • 查询服务可能限流或暂时不可用，遇到提示时稍后再试，不要连续刷新或反复提交。
    •
